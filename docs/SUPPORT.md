# KinBeacon support

**Contact:** open an issue at https://github.com/devzahirul/KinBeacon-iOS/issues or email the developer listed on the
App Store page. We answer within 2 business days.

## Getting started
1. **Parent:** install KinBeacon → *I'm a parent* → create your account → name your family.
2. **Add a child:** Family → *Add a child's device* → enter their name → a 6-digit code appears (valid 10 minutes).
3. **Child's iPhone:** install KinBeacon → *This is my child's device* → enter the code → allow Location
   (*Always*), Notifications and Screen Time.

## Common questions
**My child's location isn't updating.** On the child's iPhone: Settings → KinBeacon → Location → *Always* and
*Precise Location* on. KinBeacon's Help tab shows which permission is off; the parent app shows an alert too.

**School Mode doesn't block apps.** Screen Time must be allowed on the child's iPhone (KinBeacon → Help → Device
protection). For the strongest protection the child's Apple Account should be in your Family Sharing group — then
Screen Time access can only be removed with your approval.

**Which apps are allowed during School Mode?** On the child's iPhone: KinBeacon → Settings → *Apps allowed during
School Mode*. Apple keeps each device's app list private to that device, so the list is chosen there.

**Where do I see screen time?** Activity tab. Usage is drawn by Apple's Screen Time inside its privacy sandbox; it
needs Family Sharing between your devices.

**How do I delete my account?** Settings → *Delete account*. If you are the only parent, the whole family and all its
history are permanently deleted.

**Try it without an account:** onboarding → *Try the demo* runs a simulated family on your phone.
